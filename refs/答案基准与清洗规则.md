## 四、清洗规则参考实现（伪代码）

```python
# 1) 读取：保留原始值，不信任第 1 行表头
ws = workbook[sheet]
header_row = find_first_row_containing(ws, ['序号', '项目', '客户编码'])  # 通常第 4-5 行
headers = expand_merged_headers(ws, header_row, header_row + 1)

# 2) 清理数值：文本数字 -> float
def to_num(v):
    if v is None: return None
    if isinstance(v, (int, float)): return float(v)
    s = str(v).strip().replace('\u3000', '').replace(',', '').replace('¥', '')
    if s in ('-', '—', '－', '/'): return 0.0
    neg = s.startswith('(') and s.endswith(')') or s.startswith('（') and s.endswith('）')
    s = s.strip('()（）').replace('－', '-')
    if s.endswith('%'): return float(s[:-1]) / 100 * (-1 if neg else 1)
    return float(s) * (-1 if neg else 1)

# 3) 清理日期：多格式解析
formats = ['%Y-%m-%d', '%Y/%m/%d', '%Y%m%d', '%Y年%m月%d日', '%Y.%m.%d', '%m月%d日']

# 4) 剔除小计/合计/备注行：
is_detail = 主键列有效 and 且 label 列不以（小计/合计/注/本周/本月）开头

# 5) 纵向合并单元格向下填充：
for group_col in ['客户名称', '部门名称', '月份', '设备名称']:
    ws[group_col] = ws[group_col].ffill()

# 6) 单位换算：万元 -> 元
amount_yuan = to_num(金额万元) * 10000

# 7) 主数据去重
customers = customers.drop_duplicates(subset=['纳税人识别号'], keep='first')
```

## 八、评分建议

| 维度 | 建议权重 | 评分要点 |
|---|---|---|
| 口径正确性 | 35% | 是否识别不含税/含税、万元/元、净额/原值、季度/年度期初等口径差异 |
| 数据清洗 | 30% | 是否正确处理表头定位、合并单元格填充、小计行剔除、文本数字/日期解析、单位换算 |
| 结果准确性 | 20% | 与本文标准答案的偏差（金额允许 ±1 元以内，比率允许 ±0.01pp） |
| 勾稽验证意识 | 10% | 是否主动用三表勾稽、明细-总账勾稽、存货/应收应付明细核对结果 |
| 解释与洞察 | 5% | 是否指出异常（如收入未达预算、毛利率下滑、经营现金流低于净利润）并给出原因假设 |

**分级参考**：

- A（优秀）：陷阱题 Q33-Q40 全部正确处理，基础/分析题误差在容差内，能说明口径与勾稽
- B（良好）：基础题正确，陷阱题大部分正确，个别口径需提示
- C（合格）：基础题基本正确，但落入 2 个以上陷阱（如小计重复加总/万元当元/合并单元格未填充）
- D（不合格）：无法定位表头或无法给出可核对的合计值
