# 03 工作簿盘点

## 目标

为每张表确定表头、角色、键、数据范围和异常类型，供后续映射人复核。

## 前置条件

01 完成，原件只读。

## 输入

原工作簿及其中的「数据字典与口径」。下表右栏为统一逻辑表名，原表名须精确保存。

## 详细任务清单

| 工作表 | 逻辑名及粒度 |
|---|---|
| 封面与使用说明 / 数据字典与口径 | cover（索引）/ dictionary（口径，逐条审核） |
| 经营驾驶舱 | dashboard，指标×情景，按行定单位 |
| 利润表 2026Q3 / 现金流量表 Q3 / 资产负债表 2026-09-30 | pnl / cashflow / balance，项目×期间或时点×情景 |
| 销售目标达成 / 月度收入趋势 / 费用预算表 | target 销售员×月 / trend 区域×月×年度 / budget 部门×科目×月 |
| 销售明细（含退货） / 费用明细 Q3 / 采购明细（万元） | sales / expense / purchase，源单据行 |
| 制造费用明细 / 生产日报 Q3 / 设备OEE周报 / 产能与产量 | overhead 工厂科目月 / production 报工行 / oee 设备周 / capacity 工厂月 |
| 库存-成品收发存 / 库存-原材料收发存 / 库存-在产品 | fg 产品仓月 / material 物料仓月 / wip 工厂月 |
| 应收账龄 0930 / 应付账款明细 | ar / ap，期末发票 |
| 人工成本明细 / 质量与客诉 / 在手订单台账 | labor 部门月 / complaint 工单 / backlog 在手订单快照 |
| 客户主数据 / 产品主数据 / 供应商主数据 / 组织与部门 | customer / product / supplier / org，来源编码 |

1. `chatbi inspect` 计算文件哈希、workbook epoch，读取工作表名、合并区域、隐藏列、公式与缓存。顺序读取 OOXML 合并/列元信息，再用 openpyxl 只读行迭代；勿按全表矩形逐格随机取值。
2. 在前 24 行以目标字段组合定位表头，记录一或两层起止行、子列、列号、单元格坐标。展开仅限合并范围，拼接父/子标题，垂直表头只取一次。同名路径保留列号待确认。利润表第 4–5 行、资产负债表第 4 行、驾驶舱指标块第 11–12 行可作定位校验。封面只记元数据；驾驶舱文字结论不作指标或提示。
3. 逐表登记有效键、数据块、行类型（明细/报表项目/汇总/标题/空/注/异常）、分组边界、单位、报告期/情景、隐藏和敏感字段。隐藏范围读取 min/max，电话、银行账号即使可见也排除；税号仅限本地去重。未知或重复匹配列标记待确认；输出清单供 04 使用。

## 交付物

`config/profiles/sheets.yaml`、`src/chatbi/ingest/inspect.py`、`var/stage/inventory.json`、`tests/test_s03.py`。

## 验收条件

1. `chatbi inspect && python -c "import json; d=json.load(open('var/stage/inventory.json')); assert len({s['name'] for s in d['sheets']})==28; print(d['sha256'])"` 输出与风险文档相同的哈希。
2. `pytest -q tests/test_s03.py -k headers` 通过；核对上述三个表头区间、目标表“7月/实际”与“8月/实际”可分别定位，以及换序/插行样本。
3. `pytest -q tests/test_s03.py -k inventory` 通过；28 表各有唯一逻辑名与处置、每个物理列有坐标，隐藏列及可见敏感列被标记，封面与指标卡的文本结论没有被当作数据行。

## 常见坑

OOXML 的只读迭代器不直接提供完整合并范围。max_row 包含备注；预算表转长后一个物理行对应多个月。

1.5–2 小时。与 02 并行。
